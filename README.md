# 一起学雅（ielts-learning）

## 这是啥

备考雅思期间，我被两个软件体验搞得血压飙升，于是自己攒了这个：

- **背词的**：想上传自己整理的生词和词组到背词软件，结果只让输单词，短语词组都不支持。于是某天刷小红书的时候受到了小红书博主 @BATACO云天 的同义替换程序的启发，自己也可以vibe-coding一个小程序。因此在同替小程序的基础上，添加了可上传自己词书/短语/同替词和记忆复习功能。
- **听写的**：听写王陆语料库，那个间隔短得我怀疑人生，单词还没写完就跳到下一个了，明明有些单词我并不是不会拼写。干脆自己写了一个听写的小程序，间隔随便调。

没有后端，没有 App，打开就能用。词书格式自己定，雅思、托福、四六级，能出成 txt 的都能背。

如果觉得能用就 star 一下呀，祝大家屠雅顺利。

> 学习进度与上传内容仅保存在本机浏览器，不会上传服务器。

## 页面说明

| 文件 | 功能 |
|------|------|
| `一起学雅.html` | 整合了单词听写 / 同义替换，并另外增设了 词汇闯关 模块|
| `单词听写.html` | 上传 TXT 词表，朗读听写；输入答案自动判分，答对自动进入下一词 |
| `538雅思同义替换学习复习小程序.html` | 雅思 538 考点词刷词 + 记忆复习（错词本） |

### 单词听写

- 上传每行一词的 `.txt`，或使用内置示例
- 朗读后在输入框作答，回车判分
- 答对：约 0.8 秒后自动跳到下一词
- 答错 / 看答案：显示正确答案，手动点「下一个」继续
- 全部完成后可一键**复盘错词**
- 未作答：按设定间隔自动滚词（可当作跟读模式）

### 同义替换

- 内置 538 同义替换，先回忆再翻卡
- 错词自动进入复习模式，支持记忆进度本地保存
- 也可上传自定义「单词 + 释义 / 同义替换」，短语词组也能录

### 词汇闯关

- 60 秒限时答题，连击加分
- 题目来自自定义词表，词表充足时支持听音选词

## 本地使用

直接双击对应 `.html` 文件，或用任意静态服务器托管本目录。
