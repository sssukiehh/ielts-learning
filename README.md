# 一起学雅（ielts-learning）

纯前端雅思学习小工具，无需服务器，浏览器直接打开即用。学习进度与上传内容仅保存在本机浏览器。

## 页面说明

| 文件 | 功能 |
|------|------|
| `一起学雅.html` | 整合入口：单词听写 / 同义替换 / 词汇闯关 |
| `单词听写.html` | 上传 TXT 词表，朗读听写；输入答案自动判分，答对自动进入下一词 |
| `538雅思同义替换学习复习小程序.html` | 雅思 538 考点词刷词 + 记忆复习（错词本） |

### 单词听写

- 上传每行一词的 `.txt`，或使用内置示例
- 朗读后在输入框作答，回车或点「确定」判分
- 答对：约 4 秒后自动跳到下一词
- 答错 / 看答案：显示正确答案，手动点「下一个」继续
- 未作答：按设定间隔自动滚词（可当作跟读模式）

### 同义替换

- 内置 538 组同义替换，先回忆再翻卡
- 错词自动进入复习模式，支持记忆进度本地保存
- 也可上传自定义「单词 + 释义 / 同义替换」

### 词汇闯关

- 60 秒限时答题，连击加分
- 题目来自自定义词表，词表充足时支持听音选词

## 本地使用

直接双击对应 `.html` 文件，或用任意静态服务器托管本目录。
